# Frontend

Next.js App Router + TypeScript + Tailwind + shadcn/ui + Recharts. Needs the backend running (`NEXT_PUBLIC_API_URL`, see `.env.example`).
Check before done: `npm run lint && npx tsc --noEmit`; `npm run build` for larger changes.

## Where things live
- `app/(app)/` authenticated pages: `/` dashboard, `strategy-desk`, `backtest` (+`new`), `results/[id]`, `pnl`, `knowledge`, `settings`.
  `app/login/` is the only public page (also sign-up and demo logins unless `NEXT_PUBLIC_DEMO_LOGINS=false`).
- `components/layout/app-shell.tsx` sidebar. `components/strategy-desk/` (desk, pipeline view), `results/`, `pnl/`, `ui/` (shadcn).
- `lib/api.ts` all backend calls; `lib/api-types.ts` is generated by `npm run gen:api` from the backend OpenAPI schema, so do not hand-edit it
  except to match backend schema changes when the backend cannot run.
- `lib/auth.tsx` + `lib/token.ts`: token in localStorage, sent as a Bearer header; a 401 redirects to `/login`.
- `lib/levels.ts` experience levels, `lib/expiries.ts` upcoming expiries dropdown (computed from the usual weekday; there is no live exchange list), `lib/trade-plan.ts`, `lib/format.ts`, `lib/dates.ts`, `lib/use-load.ts`.

## Rules
- Show lots, stop, target and all P&L exactly as the backend returns them; never recompute trading numbers in the UI.
- Keep the "educational only, not financial advice" disclaimers and the NIFTY / BANKNIFTY-only scope (FINNIFTY / MIDCPNIFTY stay disabled).
- Reuse `components/ui` and existing result components before adding new ones. Strategy Desk polls `GET /runs/{id}`; `?run=<id>` reopens a run.
